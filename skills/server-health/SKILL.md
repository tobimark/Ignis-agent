# 服务器健康检查

逐项收集本机状态并给出结论。**任何一步失败都记录原因后继续**，不要中断整次检查；缺的工具照实说明，不要假装检查过。

## 步骤

1. **磁盘**：用 `shell_run` 执行 `df -h`，看各挂载点的使用率；把使用率**超过 85%** 的挂载点单独列出（挂载点 + 使用率）。
2. **内存**：用 `shell_run` 执行 `free -m`，记录总量、已用、可用与 swap 情况；可用内存明显偏低时在结论里点明。
3. **Docker**：用 `shell_run` 执行 `docker ps`，记录运行中的容器数量与名称；命令不存在（`command not found`）或守护进程未运行时，注明「未安装 / 未运行」并继续下一步。
4. **按需补充**：需要磁盘细节时用 `shell_run` 跑 `df -h <挂载点>` 或 `du -sh <目录>`；需要验证网络连通性时用 `http_fetch` 取一个明确 URL。
5. **汇总**：按「磁盘 / 内存 / Docker」三行给出状态与关键数字，对超阈值或吃紧的项给出具体建议（清理日志与缓存、清理悬空镜像、扩容等）；缺失的检查项照实标注。
