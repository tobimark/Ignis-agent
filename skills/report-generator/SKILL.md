# 报告生成

把已有的结论、命令与输出整理成一份中文 Markdown 报告。**只用手上已有的证据**：缺数据就写「未采集」，不编造数字。

## 步骤

1. **收集素材**：列出这次要写进报告的事实、命令与其输出（来自本任务的工具结果或用户给的资料），先确认每条都有出处。
2. **写 `## 概述`**：两三句话说明报告的主题、范围与结论。
3. **写 `## 证据`**：逐条给出命令与关键输出——命令用行内代码（如 `df -h`），输出放进围栏代码块；输出只留关键几行，过长就截断并标注 `…（截断）`。
4. **写 `## 结论`**：给出判断与后续建议，逐条对应上面的证据；事实与推断分开写，不确定的标「待确认」。
5. **落盘（按需）**：用户要求保存成文件时，用 `fs_write` 写入工作区（例如 `report.md`），写操作会走审批；没要求就只在回复里给出报告。
