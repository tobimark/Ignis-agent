# Ignis v0.2 阶段一（P1）：事件层与流式渲染 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 把「原样透传 + 原始回显」的终端输出，升级为有纪律的渲染：事件契约支持推理分道与工具配对；native / codex / claude 三个内核都产出推理与工具完成事件；CLI 渲染器按 Minimal / Normal / Debug 三种模式流式渲染 Markdown 子集、工具状态行（含耗时）与收敛的结束行；启动屏版本号动态、记忆段文案修正；上层配置 `ui.*` 就位。

**架构：** 改动集中三处——`packages/runtime`（事件契约 + `think.rs` 分割器 + 三内核映射）、`packages/core`（`TaskOutcome` 增加工具计数；`Config` 增加 `ui` 段）、`apps/cli`（`render/` 拆为 `mod.rs` / `width.rs` / `markdown.rs` 三文件；命令层接线）。渲染器只消费事件、不碰内核；内核只产出事件、不 `print`。

**技术栈：** Rust（edition 2024）；**零新增依赖**（Markdown / 宽度表 / 颜色全部手写；不引入 ratatui / crossterm / termimad / unicode-width）。

**Spec：** `docs/superpowers/specs/2026-10-16-ignis-v0.2-design.md`（与 `docs/superpowers/specs/2026-10-15-ignis-v0.1-design.md`、README 一并阅读；冲突以 v0.2 设计文档为准）。本计划只覆盖 P1；P2–P6 见设计文档 §7。

## 全局约束

来自 v0.2 设计文档 §3，适用于本计划所有任务：

- **零新增依赖**：不添加任何 crate（含 dev-dependencies）。Markdown、宽度、颜色、分割器全部手写。
- **语言**：代码注释与文档中文；CLI 用户可见文案与模型可见工具描述英文；工具结果与错误信息中文。
- **收口验证**：每个任务收口跑 `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`，全绿、零警告。
- **测试 hermetic**：不碰真实 `~/.ignis`；临时目录用各 crate 既有手法（`TempDir` 夹具 / `std::env::temp_dir`），不依赖网络与真实模型。
- **事件契约**：`RuntimeEvent` 的 serde 形状即 JSONL 格式；新增字段必须 `#[serde(default)]` 兼容旧日志；快照测试同步更新；`task show` 对未知/缺失字段继续容忍。
- **生产路径无 panic、错误对人话**；不打印密钥（Debug 模式也只渲染摘要与首行）。
- **提交**：Conventional Commits，英文 type/scope + 中文正文；一次提交一个可验证单元。
- **不 Delta 化既有语义**：`RunStatus::as_str` 契约字符串（`success`/`failed`/`aborted`/`limit_reached`）、上限标记字符串（`max_steps`/`task_timeout`/`token_budget`）、退出码（0/1/130）一律不动。

## Review Focus

以下五类情形设计文档未逐条展开、但真实用户会撞上；每条都已绑定到具体任务的测试，执行者必须让这些测试存在且通过：

1. **流式输出丢字 / 重字 / 布局错乱**：任意分片切分下，渲染结果必须与整体投喂逐字节一致（含围栏与行内标记被切断、跨多字节 UTF-8 边界）。测试在 Task 6（随机 100 次分片不变量）与 Task 9（e2e 冒烟）。
2. **推理标记泄漏或吞文字**：`<think>` / `<thinking>` 跨分片、未闭合到流尾、`reasoning_content` 另一条通道，都不允许标签出现在正文通道、也不允许吞掉文字。测试在 Task 2。
3. **旧数据兼容**：缺 `call_id` 的旧 JSONL 可反序列化、旧日志照常 `task show`；新增事件变体不破坏既有渲染。测试在 Task 1、Task 8。
4. **终端兼容**：非 tty / `NO_COLOR` 下零 ANSI；CJK 宽度正确；tty 下按宽度折行不丢字符、不重复；无配对结果的工具行不崩。测试在 Task 5、Task 8（单元）与 Task 9（e2e）。
5. **取消 / 失败语义**：中断不显示 Done、失败行与退出码一致、结束行不与流式文本粘在同一行。测试在 Task 8（footer 矩阵 + `finish()` 换行）与 Task 9（`limits` 回归）。

**Interfaces:**
- Consumes: Task 1–7 的全部产出。
- Produces：
  - `render::{RendererOptions, Renderer}`：
    `RendererOptions { mode: OutputMode, color: bool, theme: Theme, width: usize }`（`width = usize::MAX` 表示不折行）；
    `Renderer::new(out: Box<dyn Write + Send>, options: RendererOptions, saw_schedule_create: Arc<AtomicBool>) -> Self`；
    `on_event(&mut self, ev: &RuntimeEvent)`；`finish(&mut self)`（冲刷挂起内容并保证换行）。
  - `render::resolve_color(choice: ColorChoice, is_tty: bool, no_color: Option<&str>) -> bool`（`NO_COLOR` 非空 → 恒 `false`（含 `Always`）；`Never` → `false`；`Always` → `true`；`Auto` → `is_tty`）。
  - `render::palette(theme: Theme) -> Palette`（`dim` / `bold` / `error` / `accent` 四个 ANSI 串；dark `dim=\x1b[2m`、light `dim=\x1b[90m`，其余两档一致）。
  - `render::format_task_end(id, status, elapsed, usage, skills, tool_calls, mode) -> String`：
    normal `● Done · 2.1s · 3 tools · task 019a1b2c-3d4e`（非成功 → `● Failed|Aborted|Limit reached · …`；`skills` 非空追加 `· skills: a,b`）；
    debug 在 task 前追加 `· tokens in=1234 out=567`（`estimated` 前缀 `~`）且 task 用完整 id；
    minimal `● Done · 2.1s`。
  - `render::short_id(id: &str) -> String`（取 uuid 前 13 个字符）。
  - `storage::Db::task_ids_with_prefix(prefix: &str, limit: usize) -> Result<Vec<String>>`。
- 渲染行为契约（测试锁定）：
  - 工具行（normal）：起始 `→ {summary}`（dim）；成功 `  ✓ {summary} · 0.3s`；失败 `  ✗ {summary} · 0.3s`（红）+ 下一行 `    {输出首行 ≤200 字符}`（红）；配对优先 `call_id`，`call_id` 为空时按 FIFO 配对；无配对的 `ToolResult` 只打结果行（无摘要时用工具名）。minimal 不出工具行（只由 footer 计数）。
  - 推理（normal）：块首 `· ` 前缀、dim 流式；minimal：不显示内容、块结束时打一行 dim `· thinking (N chars)`；debug：块首 `[reasoning]` 前缀、dim 流式。
  - 正文：经 `MdStream` + `width::wrap`；宽度规则——stdout 是 tty 时取 `TIOCGWINSZ`（失败/0 回退 80），非 tty 用 `usize::MAX`（不插入物理换行，保持每行可 grep）；前缀类块（引用/列表/代码）按宽度折行并保持续行对齐；ANSI 不计宽。
  - `finish()`：`MdStream::finish` 冲刷 + 若最后输出不以 `\n` 结尾则补一个（修复结束行粘连）。
  - `remember` 成功结果行固定为 `  ✓ memory: {key} ({scope}) {text ≤60 字符}`（参数从该 `call_id` 的 `ToolExec.args` 取；缺字段时退回普通成功行）。
  - `color=false` 时输出零 ANSI（测试断言不含 `\u{1b}`）。
  - banner：`IGNIS v{env!("CARGO_PKG_VERSION")}`；第 4 行 `Runtime: {k} · Skills: {n} · Memory: {n} facts`（0 也一样，不再出现 `off`）。
  - `task show <前缀>`：全等 → 命中；否则 `task_ids_with_prefix`（要求参数 ≥8 字符且只含 `[0-9a-f-]`）：1 命中 → 使用，0 → `error: task not found: {arg}`，多命中 → `error: ambiguous task id: {arg}（候选：a, b, …）`。`task list` 与结束行统一用 `short_id`（13 字符）。
- 接线（`commands/mod.rs`）：options 由 `config.ui` + `std::io::stdout().is_terminal()` + `std::env::var_os("NO_COLOR")` 组成；**渲染改为在同一任务内与 `runner.run` 交错消费事件（替换原 spawn 的渲染任务，run 返回后把剩余事件排干）**，工具行 / 结束行从列 0 开始；任务结束后先 `renderer.finish()` 再打印 `format_task_end(...)`（传 `outcome.tool_calls` 与模式）；REPL 在 `run_task` 返回后补一行空行，`ignis run` 不补。审批提示的写序竞态为已知限制（P2/P5 收口）。
