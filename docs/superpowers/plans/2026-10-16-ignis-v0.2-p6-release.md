```rust
// apps/cli/src/commands/mod.rs（新增）
/// REPL 启动时把进程级 SIGINT 处理器**提前装好**（一次），返回的句柄由调用方持有到进程退出。
///
/// 今日的竞态：`tokio::signal::ctrl_c` 的处理器在 future **首次轮询**时装，而
/// `spawn_ctrl_c_watcher` 是「每段现起」——第一段 watcher 被轮询之前到达的 SIGINT 走默认处置，
/// 直接杀掉进程（P5 台账记的偶发信号退出）。这里在进第一段等待之前先装一次，安装先于任何
/// 可交互时机；之后各段 watcher 复用同一个已装好的处理器（监听者各自成流，互不消耗）。
///
/// 实现口径：`tokio::signal::unix::signal(SignalKind::interrupt())` **调用即注册**（不是首次
/// 轮询），把返回的流移进后台任务持续 `recv()` 即完成安装；非 unix 返回 `None`（REPL 本身
/// 也是 unix 门控，行为退化为今日）。安装失败（不支持的平台）同样 `None`，不 panic。
pub fn install_ctrl_c_handler() -> Option<tokio::task::JoinHandle<()>>;
// spawn_ctrl_c_watcher(cancel) 的签名与行为**不变**（每段的取消监听照旧）。

// apps/cli/src/editor/raw.rs（填补既有函数的行为）
/// 退出路径的 best-effort 还原：除按 [`ACTIVE`] 记录复原 termios 外，**还要关掉 bracketed
/// paste**（`\x1b[?2004l`）。空闲 Ctrl+C 退出时读取线程仍握着守卫阻塞在 `read` 里，进程退出不会
/// 析构它，`Drop` 的关闭序列因此永远不会写出——用户的 shell 会残留粘贴模式。
/// 没有活跃记录时不写任何字节（既有的「无操作」语义保留）；锁中毒一律不动终端。
pub fn restore_terminal();
```

- 行为契约（测试锁定）：
  - `install_ctrl_c_handler()` 在 unix 上返回 `Some`；在它之后 `spawn_ctrl_c_watcher(token)`，`libc::raise(SIGINT)` 能让 `token` 在 2s 内取消（安装生效的判别）。重复调用不 panic、不改变行为。
  - 安装点在 `repl::run` 里**先于** `choose_reader` / banner / `repl_loop`：空闲 / 任务 / 命令三段的 watcher 都建立在已装好的处理器之上；`repl::run` 退出时的 `raw::restore_terminal()` 调用点不变。
  - `restore_terminal()`：有活跃记录时写 `\x1b[?2004l` 并复原 termios；无活跃记录时零字节（既有用例 `restore_is_a_noop_without_an_active_guard` 类断言不动）。
  - pty：空闲 Ctrl+C 退出 `wait() == 0`（不是信号退出）；退出流里在「发 `\x03` 之前的偏移之后」出现 `\x1b[?2004l`。

```rust
/// 制表位步长：`\t` 前进到下一个 8 列的整数倍（与 TUI 滚动区的显示口径一致）。
pub const TAB_STOP: usize = 8;

/// 从 `column` 列消费一个字符后的新列位置：`\t` 跳到下一个 [`TAB_STOP`] 的整数倍，
/// 其余按 [`char_width`]（`char_width('\t')` 仍是 0，既有口径不动）。
pub fn advance_column(column: usize, c: char) -> usize;

/// 把 `\t` 展开成空格（**仅显示层**：调用方拿它去画，不改任何被提交/落盘的文本）：

/// 与 [`frame`] 同一个帧协议，但把每个逻辑行按**显示宽度**折成多个物理行（`width` = 终端总列数）。
///
/// - 每个物理行的可用列 = `width - 该行标记的显示宽度`，下限 1（保证每行至少消费一个字符，
///   宽字符放不下时整字放行、不死循环）；
/// - 折叠前先按该物理行的起始列（首行 `prefix` 宽度、其余 `continuation` 宽度）展开 `\t`；
/// - `width == usize::MAX` 时不折行、不展开 `\t`，输出与 [`frame`] 逐字节相等；
/// - 光标行/列按折行后的物理行算，帧尾的 `\x1b[{n}A` / `\x1b[{m}C` 口径不变。
pub fn frame_with(prefix: &str, continuation: &str, text: &str, cursor: usize, width: usize) -> String;
// frame(prefix, continuation, text, cursor) 签名与字节不变，内部 = frame_with(..., usize::MAX)。

// apps/cli/src/editor/reader.rs（私有接线，不外露 API）
// read_line 开始时探一次宽度：`width_for_stdout(std::io::stdout().is_terminal())`
// （非 tty → usize::MAX，与今日「交给终端软换行」逐字相同）；`draw` 与 `finish_submit`
// 改调 `frame_with(..., 这份宽度)`。

// apps/cli/src/tui/input.rs
// `InputState::block()`：两个显示行都按该行标记宽度 `expand_tabs(内容, marker_cols)` 后落进
// `InputBlock.lines`（里面不再含 `\t`）；光标列在**展开后的**文本上算；窗口选取逻辑（按逻辑行）
// 与 `hint` 行不变。
```

  - `expand_tabs("a\tb", 0) == "a       b"`；`expand_tabs("\t", 3) == "     "`（5 空格）；`expand_tabs("你\t", 0) == "你      "`（6 空格）。
  - `frame_with("❯ ", "… ", "abcdef", 6, 5) == "\r\x1b[J❯ abc\r\n… def\r\n\x1b[1A\r\x1b[5C"`。
  - `frame_with("❯ ", "… ", "你你你", 3, 5)` 的两行是 `❯ 你` 与 `… 你`（宽字符不切开）。
