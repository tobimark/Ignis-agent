# Ignis v0.2 阶段二（P2）：输入编辑器与命令系统 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 把「单行只读输入 + 三个斜杠命令」升级为 v0.2 的输入面：手写 raw mode 行编辑器（多行编辑、持久历史、Tab 补全、bracketed paste、中日韩宽度正确的重绘、Ctrl+C / Ctrl+D 语义与 v0.1 一致、终端不支持时回退行模式）＋本地命令框架（14 个命令里 P2 的 9 个非会话命令、未知命令本地报错不再发模型、`/help` 分组）。

**架构：** 新增 `apps/cli/src/editor/`（`raw` 守卫 · `keys` 解码 · `state` 状态机 · `draw` 重绘帧 · `history` 历史文件 · `reader` 读取层）与 `apps/cli/src/commands/slash.rs`（命令表 + 解析 + 纯渲染 + 分发）；`repl.rs` 拆为 `repl/` 目录，`LineReader` 接缝原样保留（编辑器只是它的一个新实现，每次读取仍走脱离线程 + oneshot）。`Session` 增加会话级状态（输出模式 / 模型覆盖 / 最近一轮用量），渲染与内核选择照旧——P1 的事件层、渲染器、三个内核**一行不改**。

**技术栈：** Rust（edition 2024）；**零新增依赖**（raw mode 与 `openpty` 都走 `apps/cli` 已允许的 `libc`；宽度复用 P1 的 `render::width`，不做组合字符簇与 bidi）。

**Spec：** `docs/superpowers/specs/2026-10-16-ignis-v0.2-design.md`（重点 §6.4 输入编辑器、§6.5 命令系统、§6.11 配置、§7 的 P2 行、§10 风险 1/6、§2.2 非目标）。本计划只覆盖 P2；`/new` `/sessions` `/resume` 与 `/compact`（P3）、`/context`（P3）、`/skills reload` 与 `remember` 确认行（P4）、`/learn`（P4）**不实现、也不在 `/help` 里列出**。

## 全局约束

来自设计 §3 与本阶段控制器决策，适用于本计划所有任务：

- **零新增依赖**：不添加任何 crate（含 dev-dependencies）。raw mode、`openpty`、按键解码、重绘、补全全部手写。
- **语言**：代码注释与文档中文；**本期新增的 REPL 界面文案（`/help`、`/status`、`/model`、`/details`、命令回显、未知命令、编辑器提示与告警）一律英文**（§3「CLI 用户可见文案英文」；v0.1 `/help` 的中文描述随本次重排改成英文，属有意变更）；**复用**的既有文案保持原样：`/memory` 的输出与错误沿用 `commands/memory.rs` 与 core 的中文（`已记住（…）`、`已改写（id=N）`、`memory not found: {id}`、`检索词不能为空`），`/kernel` 切换失败沿用 `Session::set_kernel` 的中文错误，`note:`/`error: {人话}` 前缀与 P1 一致。
- **收口验证**：每个任务收口跑 `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`，全绿、零警告。
- **测试 hermetic**：不碰真实 `~/.ignis`（单测传显式路径，pty 用例用临时 `IGNIS_HOME`）；不依赖网络与真实模型（假模型 `ScriptedModel`，pty 用例只用纯文本步、**不用工具调用**——pty 里 stdin 是 tty，审批会变成交互提问）。
- **生产路径无 panic、错误对人话**；编辑器与命令面不打印密钥（`/status`、`/model` 只打模型名与路径）。
- **提交**：Conventional Commits，英文 type/scope + 中文正文；一次提交一个可验证单元。
- **不 Delta 化既有语义**：退出码（0/1/130）、`RunStatus::as_str` 契约串、`Session::new` 的装配顺序、P1 的渲染契约（`RendererOptions` 形状、`resolve_color`、`format_task_end`）不动；`LineReader` trait 不动；**ISIG 保持开启**——Ctrl-C 仍是 SIGINT，空闲退出 watcher 与任务取消 watcher 一行不改。
- **会话类命令不在本阶段**：`/help` 里出现 `/new` `/sessions` `/resume` `/context` `/compact` `/learn` `/reload` 视为缺陷（有测试钉住）。

### Task 2: 按键解码器（字节 → `Key`，含粘贴区间）

**Files:**
- Create: `apps/cli/src/editor/keys.rs`
- Modify: `apps/cli/src/editor/mod.rs`（`pub mod keys;`）

**Interfaces:**
- Consumes: 无。
- Produces：
  - `editor::keys::Key`：`Char(char)`、`Enter`、`Newline`、`Up`、`Down`、`Left`、`Right`、`Home`、`End`、`Backspace`、`Delete`、`CtrlD`、`CtrlU`、`CtrlC`、`Tab`、`PasteStart`、`PasteEnd`、`Other`（`Copy + Eq + Debug`）
  - `editor::keys::Decoder`：`new()`、`feed(&mut self, bytes: &[u8]) -> Vec<Key>`、`take_invalid(&mut self) -> bool`、`pasting(&self) -> bool`
- 解码表（测试锁定）：

| 输入 | Key |
|---|---|
| `\r`(0x0D) | `Enter` |
| `\n`(0x0A) | `Newline` |
| `\x1b\r`（Alt+Enter） | `Newline` |
| `\x1b[A` / `\x1bOA` | `Up`（`[B`/`OB` → `Down`，`[C`/`OC` → `Right`，`[D`/`OD` → `Left`） |
| `\x1b[H` / `\x1bOH` / `\x1b[1~` | `Home`；`\x1b[F` / `\x1b[OF` / `\x1b[4~` → `End` |
| `\x1b[3~` | `Delete` |
| `\x1b[200~` / `\x1b[201~` | `PasteStart` / `PasteEnd` |
| `\x1b` + 其它字节 | `Other`（两字节都消耗——Alt+字符在 readline 口径下就是"没有绑定"） |
| 0x01 / 0x05 | `Home` / `End` |
| 0x04 / 0x15 / 0x03 / 0x09 | `CtrlD` / `CtrlU` / `CtrlC` / `Tab` |
| 0x7F / 0x08 | `Backspace` |
| 其它控制字节 | `Other` |
| 可打印字节 | 每个字符一个 `Char`（UTF-8 lossy） |

- 算法契约（测试锁定）：
  - **跨读取缓存**：末尾不完整的最长前缀（裸 `\x1b`、`\x1b[`、`\x1b[2`、半个多字节 UTF-8）留在 `pending`，下次 `feed` 拼上再解码；`pending` 超过 16 字节按 `Other` 丢弃并清空（防垃圾串无限缓存）。
  - **CSI 扫描**：`\x1b[` 后读参数与中间字节，遇到终结字节（`~` 或字母）结束；未识别的序列 → `Other`。
  - **粘贴区间**：`PasteStart` 置 `pasting = true`，此后**不再解释转义序列**，只在字节流里找结束标记 `\x1b[201~`（含其不完整前缀的缓存与回退：`\x1b[2m` 在粘贴里是可见字符 `[`、`2`、`m` 加一个被丢弃的裸 `ESC`）；区间内 `\r`、`\n` 只出 `Newline`，`\r\n` 合成**一个** `Newline`；**Tab 按字面插入（`Char('\t')`）**，其余控制字节（含裸 `\x1b`、DEL）丢弃，非控制字节按字面插入；非法 UTF-8 → `Char('\u{FFFD}')` 并置 invalid 标志。
  - **`take_invalid`** 取走即清零（读取层据此打印一次告警，见 Task 7）。

覆盖：`enter_and_newline_are_distinct`、`alt_enter_inserts_a_newline`、`csi_and_ss3_arrows_decode`、`home_end_and_delete_from_csi_and_ss3`、`control_keys_map_to_their_bindings`（上表逐条，含 `\x02` → `Other`）、`escape_sequences_split_across_feeds_stay_intact`（`\x1b` + `[A`；`\x1b[20` + `0~`）、`multibyte_chars_split_across_feeds_stay_intact`（逐字节喂 `你`，只在最后一个字节后得到 `Char('你')`）、`alt_character_is_dropped_as_other`、`paste_mode_is_verbatim_and_crlf_collapses`（`\x1b[200~\x1b[2m\r\n你好\x1b[201~` → `[PasteStart, Char('['), Char('2'), Char('m'), Newline, Char('你'), Char('好'), PasteEnd]`，且结束后 `pasting() == false`、`\x1b[A` 重新解成 `Up`）、`invalid_utf8_becomes_replacement_and_flags_once`、`pending_is_capped_and_reset`。

### Task 3: 历史文件（`~/.ignis/history`）

**Files:**
- Create: `apps/cli/src/editor/history.rs`
- Modify: `apps/cli/src/editor/mod.rs`（`pub mod history;`）

**Interfaces:**
- Consumes: 无。
- Produces：
  - `editor::history::HISTORY_LIMIT: usize = 1000`
  - `editor::history::History`：`load(path: PathBuf) -> History`、`#[cfg(test)] fn in_memory() -> History`、`push(&mut self, text: &str)`、`get(&self, index: usize) -> Option<&str>`（0 = 最新）、`len(&self) -> usize`、`entries(&self) -> &[String]`（新近在前）
- 行为契约（测试锁定）：
  - 文件格式：纯文本、一行一条、行尾 `\n`；**0600**（新建时 `OpenOptions::mode(0o600)`，已存在的宽权限文件重写时收紧）。
  - `load`：文件缺失 → 空历史；读取失败 → 一行警告 + 空历史（fail-soft）；多于 1000 行只留最新 1000 条（内存里也截断）。
  - `push`：按行拆开（一次多行提交逐行入史，历史是一行一条的纯文本格式）；空行/纯空白行跳过；与上一条相同则跳过（相邻去重）；超过上限丢最旧；随后尽力落盘——**未超上限时追加一行，超上限时整表重写**，落盘失败只打一行警告、内存条目照旧更新。
  - `in_memory`：无路径，`push` 不落盘（状态机单测用）。

    - 每次 `read_line`：先写 `draw::frame(prompt, CONTINUATION, "", 0)`（提示符出现），再循环 `read` 一个字节块 → `Decoder::feed` → **按批**交给 `EditorState`：同一 `read` 批次里的多个 `Event::Redraw` 合并为**至多一帧**（粘贴 N 字符不得写 N 帧）；`Event::Idle` 不写；`Event::Submit(text)` 先写「光标在末尾」的一帧再写 `\r\n`，返回 `Ok(Some(text))`；`Event::Eof` 直接返回 `Ok(None)`（不补换行——REPL 自己 `println!()`）。raw 守卫在该调用内进出（见上），返回前已恢复。
    - **EINTR 容忍**：`read` 返回 `ErrorKind::Interrupted` 时继续循环；`Ok(0)`（EOF / 对端关闭）→ `Ok(None)`。
    - **非法字节**：`decoder.take_invalid()` 为真时，先 `\r\x1b[J` 清掉输入行，写一行 `warning: input contained invalid UTF-8 bytes; replaced with the replacement character (check your terminal encoding or input method)`，再照常重绘（替换字符已由解码器插入）。
    - **Tab**：`Key::Tab` 不交给状态机，而是 `slash::complete(&state.text())`——`Accepted(text)` → `state.replace(&text)` 并重绘；`Listing(lines)` → `\r\x1b[J` + 逐行 `{line}\r\n` + 重绘输入行（缓冲不变）；`None` → 什么都不写。
    - `repl::run`：`let history_path = ignis_home().join("history");` → `choose_reader`；**守卫不归 `run` 持有**——每次 `read_line` 在 `EditorLineReader` 内启用 raw、返回前恢复（任务执行与审批期间终端保持 canonical/echo；也不能把守卫放进 `Arc<dyn LineReader>`：脱离线程的阻塞读会把它钉死）；`choose_reader` 只做一次 enable→drop 探针（TERM / termios / stdout 是否 tty）；回退理由非空时 `println!("{note}")`；其余循环逻辑不变（banner、空闲 Ctrl-C watcher、`next_line` 脱离线程、EOF/任务后空行）。
