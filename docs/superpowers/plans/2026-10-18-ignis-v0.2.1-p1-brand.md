# Ignis v0.2.1 阶段一（P1）：品牌与颜色 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 给经典 REPL 与 TUI 一个拿得出手的门面：火焰字形 Logo（半块字符 + 逐格颜色）与三段响应启动屏、品牌橙 `#F78340` 接入调色板（真彩 → 256 色 → 基本色三级降级）、经典路径两段式首帧（品牌块先出、状态块随后）、`--no-banner` 开关、TUI 捕获白名单形状化与顶行/输入标记品牌化、结束行状态点着色；workspace 版本升 `0.2.1`。

**架构：** 新增 `apps/cli/src/brand/`（纯函数：档位/样式判定、字模渲染、启动屏拼装），字模由 `tools/gen-flame-art.py` 从 `assets/ignis-flame-transparent.png` 一次性生成的 `brand/flame.rs` 入库——运行时零图像解码；`render/` 扩展 `ColorDepth` 与 `Palette`（`brand`/`ok`/`warn` 槽），色阶贯穿 `RendererOptions` → `ViewFacts` → `TuiView`；`repl::run` 两段式打印启动屏；TUI 开机行前置品牌块。零新增依赖不变。

**技术栈：** Rust（edition 2024，MSRV 1.98）；零新增依赖（含 dev-dependencies）；生成期脚本仅用 python3 标准库，不参与构建、不进 CI。

**Spec：** `docs/superpowers/specs/2026-10-18-ignis-v0.2.1-design.md`（主读 §3、§6.1、§6.2、§6.9、§7 的 P1 行；§11 偏差为背景）。本计划只覆盖 P1；P2–P5 在前一阶段验收后单独成计划。

**范围注记（哪些使用面不属本阶段）：** 设计 §6.2 的着色使用面里，**经典 REPL 的 `❯ ` 提示符**与**审批提示头**不在 P1——前者要重做标记的宽度测量（SGR 不能进 `editor::draw` 的列计数），随 P2 的浮层菜单一起落地；后者随用到它的事务面（P2/P3）落地。TUI 的 `❯ ` 输入标记在 Task 6 已着色（`compose` 的截断/净化本就 ANSI 安全）。菜单高亮与选择器光标行分别是 P2、P3 的交付。

- `startup_style`：`!term_supported`（TERM 缺失 / 空 / `dumb`）→ `{ tier: Minimal, depth: None, theme: ui.theme }`（**哑终端保守规则**：品牌块零 SGR，即使 `ui.color=always`）；否则 `color = resolve_color(ui.color, stdout_tty, no_color)`、`depth = color_depth(color, colorterm, term)`、`tier = tier(cols, stdout_tty, term_supported)`。

  - 上下都不透明 → `{fg(上)}{bg(下)}▀`；仅上 → `{fg(上)}{bg 默认}▀`；仅下 → `{fg(下)}{bg 默认}▄`；全透明 → `\u{1b}[0m` + 空格（确保前一格的背景色不漏进来）。
  - `True` 用 `38;2;r;g;b` / `48;2;r;g;b` + `\u{1b}[49m` 归位默认背景；`Ansi256` 用 `38;5;n` / `48;5;n`（n 由 `rgb_to_ansi256` 算）；`Basic16` 与 `None` 走**剪影**：`█` / `▀` / `▄` / 空格，零 SGR。

- `brand_block`：
  - `Minimal` → `[wordmark]`；`wordmark` = `IGNIS v{version}`，`depth != None` 时 `{bold}{brand}` 包裹（`theme` 取 `style.theme` 的 `palette(theme, depth)`）。

  - `Full` → `FULL` 的 13 行，右侧第 1 行 wordmark、第 2 行标语 `Your Personal Autonomous Agent`（`depth != None` 时 `dim` 包裹）。
- `status_block`（逐字与现 `banner_lines` 相同，仅加着色）：
  - `● Ready`（`depth != None` 时整体 `ok` 包裹）→ `\u{1b}[32m● Ready\u{1b}[0m`；
  - `Workspace: {path}`、`Runtime: {kernel} · Skills: {n} · Memory: {n} facts`、`Session: {label}` 三行**不着色**（锚点子串保护）；
  - `alerts` 为 `Some` 时追加一行、`depth != None` 时整体 `warn` 包裹。
